## Key concepts

1. **Be findable** — search "your name + data science" on Google. If the first page is empty, you don't exist professionally.
2. **LinkedIn is the resume** — recruiters use it more than your PDF. Headline, About, Skills, Featured section all matter.
3. **GitHub is the portfolio** — README on profile, pinned repos, descriptive READMEs in each project.
4. **Consistency** — same name, same headshot, same handle (where possible) across LinkedIn, GitHub, X.
5. **Headshot** — clear face, neutral background, no group crops.

## Checklists

### LinkedIn
- [ ] Professional headshot
- [ ] Banner image (relevant — code, charts, your name)
- [ ] Headline ≠ "Student" — say what you're learning toward ("Aspiring Data Scientist | Python · SQL · ML")
- [ ] About section — 3 short paragraphs: who, what, want
- [ ] Featured section — pinned posts, certificates, projects
- [ ] Skills — endorsable, with assessments where possible
- [ ] Open to work badge enabled (when applicable)
- [ ] Custom URL: linkedin.com/in/yourname

### GitHub
- [ ] Profile README (the special `username/username` repo)
- [ ] Pinned repos (6 of your best)
- [ ] Each repo has: descriptive README, screenshots, how-to-run, license
- [ ] No empty / abandoned repos pinned
- [ ] Avatar matches LinkedIn

### Portfolio site (later, in module 3)
- [ ] About / projects / blog / contact
- [ ] Hosted (Vercel / Netlify / GitHub Pages)
- [ ] Custom domain ideal
